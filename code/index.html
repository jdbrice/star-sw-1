Forward Tracking Code Structure and Flow

  • Code : StRoot/StFwdTrackMaker
  • Overview
    • Forward tracking covers pseudorapidity η ∼ 2.5–4.0 using two detectors:
      • FST (Forward Silicon Tracker): 3 disks at z ∼ 152, 165, 179 cm
      • FTT (sTGC): 4 planes at z ∼ 281, 304, 327, 349 cm
    • load MuDst → reconstruct FTT clusters/points → load FST hits → forward seed finding (KiTrack) → fit with GenFit Kalman filter → optionally associate with FCS calorimeter → write PicoDst output.
  • fwd_afterburner_db.C (StFwdTrackMaker/macro/mudst/fwd_afterburner_db.C)
    • ROOT macro that assembles and runs the STAR maker chain as an "afterburner" (post-processes existing MuDst files to re-run/improve forward tracking).
    • Key configuration flags (global booleans at top):
      • runDb — enable STAR database connection (beamline, FCS calibrations); timestamp now read from the 1st event instead of hardcoded
      • runFttChain — run FTT hit calibration, clustering, and point-making makers
      • runFcsChain — run FCS waveform fit and cluster makers
      • runFwdChain — run StFwdTrackMaker (seed finding + GenFit track fitting)
      • refillMuDst — attempt to refill MuDst from StEvent (currently broken)
      • runFwdQa — run StFwdQAMaker and StFwdAnalysisMaker for tree output
      • runFitQa — run StFwdFitQAMaker
      • runPico — run StPicoDstMaker to produce PicoDst output
      • runFwdAlignment — run StFwdAlignmentMaker (unbiased, hit-removed residuals); off by default, set per-invocation via the enableAlignment macro argument (this is how condor batch jobs turn it on without a source edit)
    • Chain order: St_db_Maker → StMuDst2StEventMaker → StFcsDbMaker (if runDb||runFitQa, needed for beamline even when FCS chain itself is off) → StFttDbMaker → StFttHitCalibMaker → StFttClusterMaker → StFttClusterPointMaker → [StFcsWaveformFitMaker → StFcsClusterMaker] → StFwdTrackMaker → [StFcsTrackMatchMaker] → [StFwdQAMaker] → [StFwdResidualMaker ×3] → [StFwdAlignmentMaker] → StPicoDstMaker → [StFwdFitQAMaker]
    • StFwdTrackMaker configuration in the macro: seed finding FST-only, track refit enabled (adds FTT hits after FST seeding), FST hit source MuDst, FTT hit source StEvent, Kalman fit iterations min=40/max=100, geometry cache fGeom.root, beamline from DB when runDb, optional applyFstWedgeAlignment (see wedge correction page).
    • Event loop: iterates MuDst events (capped at nEvents), calls chain->Make() per event, monitors memory with StMemStat. chain->Finish()/delete chain are commented out, but StFwdResidualMaker/StFwdAlignmentMaker are explicitly Finish()'d at the end so their output isn't lost.
  • StFwdTrackMaker (StFwdTrackMaker.h, .cxx) — the primary STAR maker, inherits StMaker
    • Init() — determines geometry cache file; instantiates ForwardTracker (wraps ForwardTrackMaker) and FwdDataSource; calls ForwardTracker::initialize() which sets up the TrackFitter (GenFit) and loads the geometry ROOT file; reads FST/FTT z-positions from gGeoManager with hardcoded fallbacks.
    • InitRun(runNumber) — if setUseBeamlineFromDB(true), retrieves StFcsDb from the chain and calls mForwardTracker->setBeamline(...) once per run (beamline is run-level, not per-event).
    • Make() (per-event):
      1. Get StEvent pointer; return kStOk if missing
      2. Determine primary vertex via GetEventPrimaryVertex(), priority: GEANT g2t_vertex > StMcEvent > MuDst primary vertex > VPD Vz; (0,0,0) with large uncertainty if none found
      3. Load MC tracks from g2t_track (simulation)
      4. Load FTT hits (mFwdHitLoader.loadFttHits()), FST hits (loadFstHits()), EPD/preshower hits (loadEpdHits())
      5. mForwardTracker->findTrackSeeds()
      6. mForwardTracker->doTrackFitting() on the seeds
      7. FillEvent() writes results to StEvent's StFwdTrackCollection
    • FillEvent() — creates StFwdTrackCollection if absent; for each GenfitTrackResult calls makeStFwdTrack(); adds forward vertices (RAVE vertex finder) as StPrimaryVertex objects, including the BLC vertex (see BLCVtx/index.html).
    • makeStFwdTrack() — stores FST/FTT seed hit positions and covariances; sets MC truth info; for converged fits fills chi2, NDF, pval, DCA, momentum, #fit points; projects track to z-planes of TPC (z=0), FST (3), FTT (4), FCS preshower (z=375), WCAL (z=715), HCAL (z=807); WCAL/HCAL use a straight-line projection (GenFit can't reliably extrapolate that far).
    • GenfitUtils::accept<genfit::Track*>() — sanity filter: rejects tracks with 0 points, non-converged fits, missing fitter info, or pT<0.10 GeV/c.
    • FwdVertexSource priority enum — kFwdVertexSourceUnknown (not yet searched) → kFwdVertexSourceMc (GEANT/StMcEvent) → kFwdVertexSourceTpc (MuDst primary vertex) → kFwdVertexSourceVpd (VPD Vz, sigmaXY=1cm, sigmaZ=6cm) → kFwdVertexSourceNone.
    • Default XML tracker configuration (embedded string): 1 iteration, 1 phi slice; segment criteria Crit2_DeltaPhi [0,2.0]; three-hit criteria Crit3_3DAngle/Crit3_2DAngle [0,1]; SubsetNN active (min 3 hits/track, omega=0.99); HitRemover inactive; connector distance 1 (adjacent planes only).
  • StFwdHitLoader (StFwdHitLoader.h, .cxx) — loads hits from FTT, FST, EPD into FwdHit vectors for the tracker
    • DataSource enum: GEANT=0, STEVENT=1, MUDST=2, IGNORE=3
    • FTT hit loading — GEANT: reads g2t_stg_hit, uses only odd volume_id (front modules), plane_id=(volume_id-1)/100, sigXY=0.1cm. STEVENT: reads StFttCollection points, uses the points' own covariance matrix, skips NaN entries and diagonal strips (sigma_x==sigma_y). MUDST source not implemented.
    • FST hit loading — MUDST: reads StMuFstCollection, converts (r,phi,z)→(x,y,z), covariance via makeFstCovMat(), stores local strip position. STEVENT: reads StFstHitCollection, same conversion, also keeps a pointer to the original StFstHit, iterates wedges/sensors. GEANT: reads g2t_fsi_hit, applies FstRasterizer to simulate Si readout granularity (default dr=3.0cm, dphi=0.0041rad). Optional FstWedgeAligner per-wedge phi correction applied here when enabled (see wedge correction page).
    • EPD/Preshower hit loading — STEVENT only; reads FCS preshower hits (north/south), energy threshold (default 0.2 MIP), StEpdGeom corner positions averaged; fixed covariance sigXY=4cm; always sector 7. GEANT/MuDst not implemented.
    • makeFstCovMat() — computes the FST 2D covariance by propagating cylindrical uncertainties (dr, dphi) to Cartesian (x,y) via Jacobian transform; z-error fixed at 0.1cm.
    • FstRasterizer — simulates Si strip readout for GEANT hits: quantizes r and phi to nearest strip center; minR=5.0cm.
    • Hit vector management: after pushing hits into mFwdHitsFtt/mFwdHitsFst, a second pass sets up pointers into those vectors for the hit map — done after all pushes to avoid pointer invalidation from vector reallocation.
  • FwdTrackerConfig (FwdTrackerConfig.h, .cxx) — XML-based hierarchical configuration system (TXMLEngine)
    • Storage: flat std::map<string,string>, keys are dot-separated paths with colon-separated attribute suffix, e.g. "TrackFinder.Iteration:nPhiSlices".
    • load() parses XML and maps all nodes/attributes; get<T>(path,default)/set<T>(path,value); getVector<T> parses comma-separated lists; childrenOf(path); canonize(path) strips whitespace and [0] array notation; repeated nodes indexed as path[1], path[2], ...
  • StFwdQAMaker (StFwdQAMaker.h) — QA maker that writes a TTree for offline analysis
    • Stores per-event: run/event headers, MC tracks, FTT points/clusters, FST hit points, FCS WCAL/HCAL clusters and hits, EPD hits, reconstructed forward tracks, seed track points.
    • Two modes: StEvent (default) or MuDst (setMuDstInput()).
    • TClonesArrayWriter<T> helper template for TTree branch management; FcsClusterWithStarXYZ/FcsHitWithStarXYZ attach a global XYZ position (from the FCS database) to a cluster/hit.
  • Common.h (Common.h) — small utility header: FwdTrackerUtils::labelAxis() sets TAxis bin labels; FwdTrackerUtils::nowNanoSecond() high-resolution timestamp (per-event tracking performance timing).
  • StFwdClosureMaker (StFwdClosureMaker.h) / StFwdMockMaker (StFwdMockMaker.h) — closure-test and toy-MC-based validation makers.

FST hit map (3 disks × hits per disk)
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│  STEP 1: FST SEED FINDING  (doSeedFindingIteration)         │
│  - KiTrack SegmentBuilder connects FST hits across disks    │
│  - Cellular automaton selects 3-hit track candidates        │
│  - Output: list of FST triplet seeds (Seed_t)               │
└─────────────────────────┬───────────────────────────────────┘
                          │  3 FST hits per seed
                          ▼
┌─────────────────────────────────────────────────────────────┐
│  STEP 2: INITIAL GLOBAL FIT  (fitTrack, mFitter=RefTrack)   │
│  - KalmanFitterRefTrack (blowUpFactor=1e9, sqrt formalism)  │
│  - Fits 3 FST hits → seed track with position & momentum    │
│  - Uses FULL phi pitch as σ (wide covariance)               │
│  - If convergeFully → proceed; else save failed seed        │
└─────────────────────────┬───────────────────────────────────┘
                          │  converged FST-only track
                          ▼
┌─────────────────────────────────────────────────────────────┐
│  STEP 3: ADD FTT + EPD HITS  (addFttHits, addEpdHits)       │
│  - Project fitted track to each FTT plane (4 planes)        │
│  - Hard-coded search window: dx<1.5 cm, dy<1.5 cm           │
│  - Add matched FTT hits to seed                             │
│  - Similarly add EPD hit (at large z)                       │
└─────────────────────────┬───────────────────────────────────┘
                          │  seed now has FST + FTT + EPD hits
                          ▼
┌─────────────────────────────────────────────────────────────┐
│  STEP 4: GLOBAL REFIT  (fitTrack inside refitTrack)         │
│  - KalmanFitterRefTrack on full FST+FTT+EPD seed            │
│  - Uses FULL phi pitch as σ for FST (12× underweighted)     │
│  - Longer z lever arm (FST at z~150 cm, FTT at z~280 cm)    │
│  - Output: kGlobal track (stored in globalTracks)           │
└─────────────────────────┬───────────────────────────────────┘
                          │  global tracks
          ┌───────────────┼──────────────────────┐
          ▼               ▼                      ▼
┌──────────────┐ ┌──────────────────┐  ┌─────────────────────┐
│  BLC FIT     │ │  PRIMARY FIT     │  │  FWD VERTEX FIT     │
│ (doBeamline) │ │ (doPrimary)      │  │ (doFwdVertex)       │
│              │ │                  │  │                     │
│ Add beamline │ │ Add PV point     │  │ Add fwd vtx point   │
│ hit (x,y=0)  │ │ (0,0,0) in MC    │  │                     │
│ fitTrack →   │ │ fitTrack →       │  │ fitTrack →          │
│ refitTrack → │ │ refitTrack →     │  │ refitTrack →        │
│ kBeamline    │ │ kPrimaryVertex   │  │ kForwardVertex      │
└──────────────┘ └──────────────────┘  └─────────────────────┘

refitTrack() = add more FTT/FST hits near track + final fit
  - Calls addFttHits(), addFstHits(), addEpdHits() again
  - Then fitTrack() on updated seed → final track momentum

Track Types & DCA

StFwdTrack::dca() (and StPicoFwdTrack::dcaXY()/dcaZ()) is computed by GenfitTrackResult::setDCA(): the track is extrapolated to the point of closest approach to a target — either a literal 3D point (for the types constrained through a vertex hit) or a vertical line through the target's (x,y) with z free (for Global/Beamline). The stored value is the track's own (x,y,z) at that point, not a distance; dcaXY = √(x²+y²) only reads as a true impact parameter when the target's (x,y) is near the origin. See debug/index.html, Issue #27 for a bug in this that was found and fixed (2026-07-08): a stale default track type inside refitTrack() was silently substituting the wrong target/method for some types whenever the refit step succeeded.
