Proposed change: one source of truth for the FST outer-sensor gap
=================================================================

Assumes PR23 (StFstFastSimMaker strips), PR24 (StFstSlowSimMaker) and
PR25 (StFstHitMaker global position) have landed on dev.

The 1 degree gap between the two outer sensors of a wedge is currently
written out by hand in five places. They agree today, so nothing is
broken -- but they all encode the SAME physical claim (which side of the
wedge centre-line each outer sensor sits on), and that claim can only be
changed correctly if all five move together.

Step 1 below is a pure refactor: no behaviour change, provable line by
line. Step 2 (flipping the convention) then becomes a two-line change to
one function, and is a separate decision on separate evidence.


=================================================================
STEP 1 -- centralise.  Behaviour-neutral.
=================================================================

1/5   StRoot/StEvent/StFstConsts.h            (add, after kFstrStop)

+/// Which side of the wedge centre-line an outer sensor sits on:
+///   +1  sensor 1
+///   -1  sensor 2
+///    0  sensor 0 (the inner sensor, which has no gap)
+///
+/// THIS IS THE SINGLE STATEMENT OF THE OUTER-SENSOR GAP CONVENTION.
+/// The 1 degree gap enters reconstruction, both simulators, the track
+/// fitter and the forward hit loader. All of them derive their sign
+/// from here, so the convention can only be changed in one place.
+inline int fstOuterSensorSide(int sensor)
+{
+   if (sensor == 1) return +1;
+   if (sensor == 2) return -1;
+   return 0;
+}
+
+/// Signed phi offset of an outer sensor's strips from the position they
+/// would have if there were no gap. Zero for the inner sensor.
+inline double fstOuterGapPhiOffset(int sensor)
+{
+   return -0.5 * kFstStripGapPhi * fstOuterSensorSide(sensor);
+}

=================================================================
STEP 2 -- flip the convention.  Separate decision.
=================================================================

If the fstgap measurement is accepted (see index.html: overlapping
positions 83,135 -> 0, outer chi2/ndf improves 21.9 sigma with the inner
sensor flat as control), the whole change is:

     inline int fstOuterSensorSide(int sensor)
     {
-       if (sensor == 1) return +1;
-       if (sensor == 2) return -1;
+       if (sensor == 1) return -1;
+       if (sensor == 2) return +1;
        return 0;
     }

and every one of the five sites follows automatically.

Anything reading MuDst written BEFORE this lands still needs the legacy
compensation -- see "this flag is a trap" in index.html.
