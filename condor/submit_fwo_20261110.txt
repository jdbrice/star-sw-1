# FST SENSOR OVERLAP, large sample -- RERUN for the INNER r-split.
#
# Same 1433 files, same 48x30 splitting and the same sublists as the 2026-11-05
# campaign (condor/fwo_lists_20261105/, deliberately reused so the two runs are
# directly comparable). What is new is the CODE: fstWedgeOverlap.C now fills
# gFwoProfIR[4][12][2], the inner-sensor coincidence profile split by rStrip 0-3,
# and persists it as cProfIR so hadd can merge it. The 11-05 output predates that
# array -- checked, cProfIR is absent from fwo_merged.root -- so the inner r-split
# cannot be recovered from it and needs this rerun.
#
# WHY IT MATTERS. The inner sensor has no 1 deg gap, so its overlap width is
# 128*eps - 128*d/r with no 4.27-strip pedestal: the three hypotheses give 0.99
# (pure pitch), 1.92 (the outer fit) and 3.50 (pure shift) strips at rStrip 0, a
# factor 3.5 apart, where across the whole outer range they differ by 5%. A
# 20-file run already shows the accidental-subtracted n(d=2)/n(d=0) ratio falling
# 0.765 -> 0.150 across rStrip 0-3, which pure pitch cannot produce at all. This
# run is for the PER-BOUNDARY version of that: coincidence yield is non-linear, so
# a per-wedge rotation pattern could fake part of the apparent overlap, and only
# splitting the 36 boundaries separates them -- geometry is common to all 36, a
# rotation pattern is not.
#
# The job needs no DB and no fGeom.root -- the measurement reads MuDst FST strip
# indices only, which is what makes it independent of the conventions it tests.
# script/runfwo copies fstWedgeOverlap.C from the submit-time directory, so the
# updated macro is picked up with no change to the wrapper.
#
# TIMING: the 11-05 campaign ran 12:46 to 23:15, about 11 hours wall for all 48.
# This will NOT come back inside a few hours; submit it and read it the next day.
#
# Before submitting:
#   mkdir -p /gpfs01/star/pwg_tasks/FwdCalib/akio/fwo_20261110/log
#
# Merge and read with:
#   hadd -f /gpfs01/star/pwg_tasks/FwdCalib/akio/fwo_20261110/fwo_merged.root /gpfs01/star/pwg_tasks/FwdCalib/akio/fwo_20261110/fwo_0*.root
