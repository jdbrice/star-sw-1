# FST SENSOR OVERLAP, large sample -- THE PAIR-CENTROID CAMPAIGN.
#
# SUPERSEDES submit_fwo_20261110.txt, which is probably still running. That one
# was submitted for cProfIR alone; this one has cProfIR AND everything added
# since, so there is no reason to keep both. condor_rm the earlier cluster to
# free the slots if you want them.
#
# Same 1433 files, same 48x30 splitting, same sublists as 2026-11-05 (reused on
# purpose so every campaign is directly comparable). Only the code differs.
#
# WHAT IS NEW AND WHY
#
#  hPairR4..7, hPairIR0..3 -- THE POINT OF THIS RUN. The pair map split by
#    rStrip. Fold both wedge ends to a distance from the edge and histogram
#    mine against the partner's; pairs at the same physical angle lie on
#    s = d_me + d_nb = const, so W = <s> + 1 straight from the ridge. On
#    200k events the outer ridge is five flat cells at s = 4 and gives
#    W = 5.14 (all d) / 5.37 (dropping the edge strip), against 5.20-5.35 from
#    the yield profile -- two estimators with nothing in common agreeing.
#    Split by rStrip this measures W(r) directly, which is what the whole
#    pitch-vs-radial-shift decomposition rests on, and it needs no plateau, no
#    background convention and no decision about strip 0.
#
#  hPair, hPairI, hFineI -- the same summed over r, and the inner twin of the
#    strip-to-strip map.
#
#  hClPhi/hClPhiI/hClQ/hClQI -- cluster phi size and charge against distance
#    from the edge. The per-strip occupancy says strip 0 has MORE hits than the
#    bulk (outer +12%, inner +4%) while its coincidence fraction is half the
#    plateau, which points at edge-truncated clusters: reconstructed on the
#    last strip, true position outside the silicon, no partner possible. If
#    that is right these hits are narrower and lower in charge than bulk ones.
#    If they look identical, the idea is wrong and cluster shape gives no
#    handle -- which is the answer either way.
#
# 12 slots a side in every pair map, not 4: with W ~ 5.3 my strip 0 pairs with
# the neighbour's strip ~4, and a 0-3 window loses that cell and samples the
# ridge asymmetrically.
#
# The job needs no DB and no fGeom.root -- MuDst strip indices only, which is
# what makes the measurement independent of the conventions it tests.
# script/runfwo copies fstWedgeOverlap.C from the submit-time directory, so the
# current macro is picked up with no change to the wrapper.
#
# TIMING: the 11-05 campaign ran 12:46 to 23:15, about 11 hours for all 48.
#
