Electron-gun MC: single electron @ 45°, 1000 events

← Back to FST-blind projection study | Other MC samples: 2π, 1 e-/event | 2π, 8 e-/event

Setup

  • Single-electron gun, fixed at φ=45° (narrow enough to stay inside one FTT quadrant), pt=1.5GeV, 2.5<η<4.0, vz=0, 1000 events (script/genElectron45.C).
  • Same FST-blind diagnostic as the real-data page, run through the real reconstruction chain with known truth -- StFttDbMaker → StFttSimHitMaker → StFttClusterMaker → StFttClusterPointMaker(mUseGeantData=false) → fwdTrack (script/simFttResidualTest.C) -- not the GEANT-truth blur used elsewhere for MC. StFttSimHitMaker turns GEANT truth hits into synthetic raw strip hits so the same clustering/matching code runs as on real data.

Findings

  • Precise coordinate again shows a sharp real peak at dx≈0, same as real data.
  • Unlike real data, the off-axis coordinate is also tightly peaked, for both V and H -- no wide flat background. With only one track per event there's little combinatoric occupancy, so "All candidates" here is dominated by the true cluster's own nearby strips, not unrelated background hits.
  • 2D maps show a single tight, real cluster near the true hit location, not a spread-out landscape.
  • Caveat: because this sample has essentially no background occupancy, it does not by itself test whether real data's narrow peak is an artifact of picking the closest candidate out of a large background -- that needs a higher-occupancy sample (see the 2π, 8 e-/event page).
