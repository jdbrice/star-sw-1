Misalignment-Mode Tests

Each table targets the functional form a specific misalignment mode produces (first-order geometry), rather than one generic slope fit:

  • Translation (rigid x,y shift) — FTT (Cartesian): constant Δx/Δy offset (mean/offset table above). FST (polar): appears in r·Δφ as A·sin(φ-φ0), not a straight line.
  • Rotation about the beam axis by δθ — FST: r·Δφ = r·δθ, linear in r. FTT: Δx=-y·δθ, Δy=+x·δθ, linear in the cross coordinate.
  • Length-scale / gain error — FTT only: Δx∝x, Δy∝y, linear in the self coordinate.

Profile x-bins need ≥2 raw entries; reported error is inflated by √(χ²/ndf) when >1 (PDG scale-factor method).
